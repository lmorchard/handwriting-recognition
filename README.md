# Getting a computer to turn my handwriting into text

I produce a lot of pages of handwritten journal entries, some of which are ink on paper and some of which are in digital form as PDFs from an e-ink tablet.

I'd like to convert all these into text files, but I've yet to find any tool that can reliably handle my personal handwriting. But, I've read that you can train models on your own handwriting to improve the accuracy of handwriting recognition.

So, this repo is a dumping ground of notes, code, and miscellaneous artifacts as I work through trying to figure out how to get a computer to turn my handwriting into text.

Maybe someday it will turn into a more polished project to host whatever toolchain and processing pipeline I come up with.
